# Direitos de imagem

Fotomicrografias retiradas do *Guia de Minerais Transparentes ao Microscópio Petrográfico*, de Heinrich T. Frank, UFRGS, 2018: o autor declara autorização de uso **não comercial**, conforme a página introdutória do guia disponibilizado para o projeto.

Imagens externas: Wikimedia Commons. Cada imagem mantém um link para a página original, onde devem ser conferidos autor, condições de licença, atribuição e possíveis requisitos de compartilhamento pela mesma licença. Os rótulos "consultar licença" não devem ser considerados autorização para qualquer uso.

Imagens ilustrativas de grupos não comprovam a identidade de cada espécie ou end-member. O Petrodle deve preservar essa distinção visual e documental.
