## Uso de assistentes de código

O desenvolvimento do projeto contou com suporte de ferramentas de programação assistida por IA, incluindo **Codex (OpenAI)**, conforme informado pelo mantenedor. Ferramentas assistivas podem contribuir com implementação, refatoração, testes e redação de documentação, sob revisão humana. Isso não estabelece que todo commit foi produzido pela mesma ferramenta.

| Ferramenta / linhagem | Versão verificável | Alcance do registro |
| --- | --- | --- |
| **OpenAI Codex**, assistente de código | **Não recuperada do repositório público** para as sessões históricas | Uso relatado pelo mantenedor; não atribuir um modelo ou número de build sem log específico |
| **ChatGPT, linhagem GPT-6 (OpenAI)** | **GPT-6**, revisão documental em 16/11/2026 | Apoio na organização e redação destes documentos; não representa a versão utilizada em todo o desenvolvimento anterior |
| **Git / histórico de commits** | Identificadores SHA registrados pelo GitHub | Fonte verificável da evolução do código, independente do modelo de IA |

A denominação comercial **Codex** não identifica, por si só, o modelo de base ou a sua versão. Para registrar retrospectivamente uma sessão com precisão, anote data, produto, modelo exibido, versão/build do cliente (se conhecida), objetivo, arquivos modificados, commits e verificações realizadas. Não extrapole versões históricas a partir da versão atual do ChatGPT.

- O autor e mantenedor define o escopo científico e responde pelo conteúdo e pelas decisões de publicação.

- As atribuições das imagens e o uso não comercial do guia Frank permanecem válidos independentemente da ferramenta que auxiliou a escrever o jogo.
